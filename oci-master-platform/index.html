ARCHITECTURE SUMMARY • Referencia Rápida

Mapa Mental y Arquitectura Nuclear OCI

Glosario de conceptos estructurales indispensables para defender la exposición.

01

Regions & Availability Domains

Una Región es un área geográfica localizada. Un Availability Domain (AD) es uno o más centros de datos aislados entre sí dentro de una región, con energía y refrigeración independientes.

💡 Dato clave: La red backbone entre ADs tiene latencia inferior a 1 milisegundo y ancho de banda masivo.
02

Fault Domains (FDs)

Cada AD contiene exactamente 3 Fault Domains. Son agrupaciones de hardware físico (racks, conmutadores y PDU) que permiten tolerar fallas a nivel de servidor sin necesidad de cruzar a otro AD.

💡 Regla de oro: Nunca coloques dos instancias de alta disponibilidad en el mismo Fault Domain.
03

Compartments (Compartimentos)

Unidad lógica fundamental de OCI para organizar y aislar recursos en la nube. A diferencia de AWS (que requiere crear cuentas separadas), en OCI un mismo tenancy aloja compartimentos jerárquicos.

💡 Aislamiento: Se aplican políticas IAM directamente al compartimento (`allow group Devs to manage in compartment Dev_Env`).
04

Virtual Cloud Network (VCN)

Red de software (SDN) privada en OCI. Se divide en subredes públicas o privadas. Incluye componentes como Internet Gateway (IGW), NAT Gateway, Dynamic Routing Gateway (DRG) y Service Gateway.

💡 Service Gateway: Conecta a Object Storage sin que el tráfico salga a internet público.
05

Off-box Virtualization (Gen 2)

La arquitectura Gen 2 de Oracle separa la virtualización del hipervisor central. Las tareas de red e I/O corren en tarjetas inteligentes dedicadas (SmartNICs), eliminando el "noisy neighbor" y ofreciendo máximo rendimiento.

💡 Seguridad: Impide que un atacante escape de una VM y comprometa el hipervisor físico.
06

Autonomous Database (ADB)

Motor de base de datos totalmente autogestionado con Machine Learning. Se ejecuta sobre hardware Exadata. Sus tres pilares son: Self-Driving (auto-tunning), Self-Securing (auto-parcheo en caliente sin downtime) y Self-Repairing.

💡 SLA: 99.995% de disponibilidad (menos de 2.5 minutos de parada al año).
